渔途 Fishing Voyage 正式版 v1.0.4
=================================

一、运行程序
------------
1. 将压缩包完整解压到任意可写文件夹。
2. 保持 FishingVoyage.exe 与 FishingVoyage.rcc、Qt6*.dll 及各插件文件夹在同一目录。
3. 双击 FishingVoyage.exe 启动游戏。

本压缩包已包含 Qt、C++ 运行库及游戏所需资源，无需在目标电脑另行安装 Qt、MinGW 或 Visual C++ 运行库。
运行环境：64 位 Windows 10 / 11。

不要只复制 exe 单独运行；FishingVoyage.rcc 是游戏图片与界面资源包，缺失时程序会提示资源错误。

二、存档与安全退出
------------------
- 存档、图鉴与排行榜保存在当前 Windows 用户的数据目录：
  %APPDATA%\FishingVoyage\FishingVoyage
- 游戏安装目录不会写入存档，重新解压或更新程序不会删除进度。
- 将压缩包发给其他电脑后，对方首次运行会在自己的 Windows 用户目录自动创建独立存档；压缩包本身不携带你的进度。
- 如需迁移进度，请在游戏完全关闭后，手动备份上述目录中的 save.dat、Log.dat 与 highscore.dat。
- 航行中或暂停界面按 Ctrl+Q 保存并退出；单独按 Q 不会触发退出。
- 请等待程序自行关闭后再关机或结束进程，以确保存档写入完成。

三、基本操作
------------
W / A / S / D       驾船移动
Shift               加速航行（消耗体力）
Space               冲刺闪避（短暂无敌）
鼠标左键            攻击，或选择鱼类目标
E                   震荡波（充能完成后可用）
1 - 6               使用快捷栏装备或补给品
B                   打开背包
H                   打开航海图鉴
Esc                 暂停 / 继续
Ctrl+Q              保存并退出

主菜单可点击“开始航程”新开游戏；存在存档时可点击“继续游戏”。

四、核心玩法
------------
航行：
- 向右推进以完成当前海域目标。礁石会造成伤害和眩晕，漩涡会拖慢船速。
- 保持耐久和体力；体力不足时无法完成高消耗捕鱼。

战斗：
- 鼠标左键攻击敌人。鱼叉和枪械受射程、冷却和耐久限制；装备损坏后需修理。
- 第 4 关与第 9 关会出现 Boss。Boss 拥有更高血量与伤害；五头鲨在玩家持续停留在近战范围时会加快近战节奏，建议利用冲刺、震荡波与走位脱离。

捕鱼：
1. 装备鱼竿、渔网或鱼叉后，用鼠标左键点击鱼来锁定目标。
2. 进入捕鱼判定后，无需继续对准鱼；任意位置点击左键即可执行 QTE。
3. 鱼竿需要在倒计时内连续点击；渔网与鱼叉需要在校准条进入绿色区域时点击。
4. 成功捕鱼获得金币和图鉴进度，失败或超时会消耗对应装备耐久。

五、背包、商店与修理
----------------------
- 每关结算后可进入码头补给站购买装备、补给、船只升级与装备强化。
- 装备修复价格会按本次实际恢复的耐久、装备价格和强化等级动态计算，高级装备与严重损伤的修复费用更高。
- 每种补给品都会按各自累计购买次数涨价；购买次数会随存档保存，重新打开游戏不会重置。
- 干粮恢复体力；船体修理包恢复船只耐久；紧急装备修理工具可在航行中修复当前装备。
- 背包与商店中的装备列表可使用鼠标滚轮切换更多装备。

六、开发测试模式
----------------
测试模式供开发和调试使用：
- 进入关卡提示或航行中按 O：开启/关闭测试模式。
- 开启后获得无限金币、持续恢复耐久与体力。
- 开启测试模式后按 P：打开测试商店。
- 测试模式下的通关成绩不会写入排行榜。

七、常见问题
--------------
- 启动提示资源包缺失：确认 FishingVoyage.rcc 仍与 exe 位于同一文件夹，且压缩包已完整解压。
- 继续游戏不可用：说明当前没有可读取的存档；先开始新航程并使用 Ctrl+Q 保存退出。
- 窗口显示不完整：建议使用 1280×720 或更高的可用桌面分辨率。
